# 课程编辑端（Admin Web）需求说明

本文件描述 `apps/admin-web`（课程编辑端 Web）的功能范围、关键交互与权限，用于后续拆分仓库与迭代。

## 目标与定位

- 面向课程运营/内容制作人员的后台 Web。
- 核心目标：
  - 管理动作库（视频上传、分类、版本、批量上传等）
  - 编辑课程脚本（热身 / 正式训练 / 冷身 + Pod/视频组）
  - 排课（按日期时间在日历中编排课程）
  - 输出给 TV/Coach 使用的脚本数据与资源清单（供 TV 端预下载/校验）

## 角色与权限

- 超级管理员（Super Admin）
  - 可使用全部功能（含场馆管理、账号管理、应用版本管理）
  - 当前约定超级管理员账号包含：`13689547720`、`zhiyou`
- 编课账号（Course Editor）
  - 由超级管理员创建，并授权到一个或多个课程包。
  - 只能查看、编辑、排课自己被授权的课程包内课程。
  - 不能管理场馆、设备和应用版本。
- 场馆账号（`role=venue`）
  - 用于 Coach Web 与场馆设备管理，不应进入课程编辑端（可通过 `allowedClients` 做限制）

## 主要模块

### 1. 登录

- 默认预填账号密码。
- 使用 token 会话（access/refresh）保持登录，刷新 token 自动续期。

### 2. 首页 / 导航

- 侧边栏导航可折叠。
- 样式基调保持紫/黑设计体系。

### 3. 动作库

- 单个动作：名称、动作类型（分类标签）、视频资源、版本/创建时间等。
- 上传动作视频：
  - 单个上传：必须填写动作名与分类
  - 批量上传：按文件命名规则自动创建动作（例如 `动作-类型.mp4`）
- 动作类型筛选：点击类型 chip 过滤动作列表。
- 视频预览：动作选择弹窗/列表需展示缩略图并支持播放预览（便于准确选择动作）。
- 视频封面：使用视频第一帧作为封面图（避免黑屏体验）。

### 4. 课程库（课程编辑）

#### 4.1 课程结构

- 三模块：
  - 热身（Warm up）
  - 正式训练（Work out）
  - 冷身（Cool down，可选：课程允许没有冷身）

#### 4.2 热身/冷身规则

- 显示规则一致：三竖屏同步展示同一组瀑布流视频列表，自动滚动。
- 热身/冷身的动作条目支持：动作选择 + 持续时间（秒）。
- 热身/冷身不需要动作“提示”字段（TV 不展示该提示）。

#### 4.3 正式训练：视频组 + Pod 流程

- 视频组（Video Group）用于配置每块屏幕的动作列表与站点信息：
  - 三屏模式：屏幕 1/2/3 各自一组动作列表（可复制屏幕脚本到其它屏幕）
  - 单屏模式：等同瀑布流（不需要站点输入）
- Pod（流程节点）引用某个视频组，并定义循环/组数/时间策略：
  - 循环次数（循环整个动作序列的次数）
  - 组数（每个动作做几组；三屏模式下支持每组 work/rest 时间不同）
  - work 时间策略（按组数生成多个 work 时间输入）
  - rest 时间策略（按组数生成多个组间休息时间输入）
  - 换站/换区时间（move station / move zone）与补水（hydrate/break）作为 Pod 结束类型
- Pod 结束方式：补水 / 换区 / 课程结束（影响 TV 的提示与横屏进度条分段）。

#### 4.4 模板（Template）

- 需要支持热身/冷身/正式训练模板复用：
  - 模板可命名
  - 在课程编辑模块头部提供“使用模板”按钮
  - 使用模板会覆盖当前配置（已编辑时需弹窗确认覆盖）

### 5. 排课（日历）

- 以周视图/日历方式展示，不是列表。
- 根据时间在日历中定位课程卡片位置。
- 支持复制上周排课、一键复用等。

### 6. 场馆管理（Admin）

> 用于后续多场馆运营：场馆与账号一一绑定，设备归属场馆。

- 场馆 CRUD（允许删除）
- 账号管理：
  - 创建账号（独立页面/弹窗）
  - 将账号绑定到场馆（“联系人筛选”式搜索选择）
  - 一个账号暂时只允许绑定一个场馆
- 设备管理（可选在 Admin 展示；在线状态仍需 Coach 端提供实时查看）
- 应用版本管理：
  - 上传/扫描 TV 安装包
  - 下发升级由 Coach Web 执行

### 7. 课程包管理（Admin）

- 课程包由超级管理员创建和维护。
- 新建场馆默认绑定默认课程包；超级管理员可手动给场馆绑定/解绑多个课程包。
- 一个场馆可以绑定多个课程包，但同一时间只有一个课程包处于启用状态。
- 课程包用于隔离课程与排课权限：
  - 课程可以被归入某个课程包。
  - 排课时只能选择当前课程包允许的课程。
  - 编课账号只能操作被授权的课程包。
- Admin/Coach 切换场馆当前启用课程包后，Server 触发 TV `refresh_checksum`，TV 沿用现有接口重新同步当前课表，不需要 TV App 额外适配课程包。

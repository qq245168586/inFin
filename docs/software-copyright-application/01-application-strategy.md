# 01. 申请策略

## 1. 申请类型

建议申请类型：**计算机软件著作权登记**。

项目包含 Web 管理端、后端服务、Android TV 客户端和 MQTT 网关。实务上可以作为一个整体平台申请，也可以按独立软件模块拆分申请。

## 2. 首次申请建议

首次建议以一个综合平台申请：

```text
软件全称：Infini 团课训练场馆运营系统软件
软件简称：Infini
版本号：V1.0
```

理由：

- 当前项目已经覆盖课程生产、排课、教练控课、TV 播放、设备绑定、运维调试等完整链路；
- 申请一个综合平台有利于快速形成整体权利证明；
- 之后如需融资、转让、授权或诉讼维权，可再补充拆分核心模块软著。

## 3. 可拆分申请的软件名称

如果希望更细颗粒度保护，建议按以下顺序追加：

1. **Infini TV 多屏训练播放软件 V1.0**
   - 对应 `apps/tv-android`
   - 保护 TV 多屏播放、缓存、MQTT、绑定、心跳和 APK 更新能力。

2. **Infini 课程编排管理软件 V1.0**
   - 对应 `apps/course-web` 和相关 Server 模块
   - 保护动作库、课程脚本、模板、课程包和排课能力。

3. **Infini 教练控课软件 V1.0**
   - 对应 `apps/coach-web` 和 playback session 控制接口
   - 保护现场课表、预览、开课、暂停、结束、屏幕绑定能力。

4. **Infini 场馆设备与课程包管理软件 V1.0**
   - 对应 `apps/admin-web` 和相关 Server 模块
   - 保护场馆、账号、设备、版本和课程包绑定能力。

## 4. 申请主体建议

需要先决定著作权人：

- 如果软件是你个人独立开发，著作权人可写你个人；
- 如果已有公司主体并希望后续授权/出售/融资更方便，可考虑转让或作价出资到公司后由公司申请；
- 如果未来有合伙人参与，建议先签署权属确认/授权协议，再提交申请，避免产生“合作开发”争议；
- 如果代码中存在第三方或前雇主/客户贡献，需要先核实权属。

## 5. 申请前要统一的信息

线上申请表、源代码页眉、说明书页眉、权属证明中的以下信息必须一致：

- 软件全称；
- 版本号；
- 著作权人名称；
- 开发完成日期；
- 首次发表日期；
- 开发方式；
- 权利取得方式。

如信息不一致，可能被要求补正。

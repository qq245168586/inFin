## 2. 软件功能简述

Infini 团课训练场馆运营系统软件是一套面向精品团课、功能训练和多屏训练场景的综合运营系统。软件支持动作视频管理、课程脚本编排、训练模板、课程包和排课管理；支持场馆、账号、TV 设备、版本和课程包绑定；支持教练查看今日课表、预览课程、开始/暂停/继续/结束课程；支持 Android TV 多屏客户端按场馆和屏幕号拉取课程资源、缓存媒体文件、接收实时控制指令并同步播放训练内容；支持 MQTT 控制、TV 心跳、设备在线状态、APK 更新和运维日志查询。

## 3. 技术特点简述

软件采用前后端分离和多端协同架构。后端基于 Node.js/NestJS/TypeScript 提供 REST API、权限、课程、排课、媒体、设备和 playback session 服务；Web 端基于 React/Vite/TypeScript 提供 Admin、Course、Coach、Ops 等入口；TV 端基于 Android Java 实现多屏训练播放、二维码绑定、媒体缓存、MQTT 控制和心跳上报。系统以 Server 为权威状态源，以 MQTT 作为控制通知通道，通过场馆 namespace 实现多场馆隔离，并通过 checksum、daily bundle 和本地缓存保证课程资源同步和现场播放稳定。

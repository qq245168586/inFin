# 03. 材料清单

## 1. 必备材料

| 材料 | 当前准备状态 | 说明 |
| --- | --- | --- |
| 计算机软件著作权登记申请表 | 待线上填写 | 在中国版权保护中心著作权登记系统中在线填写并按系统要求签章/上传 |
| 身份证明文件 | 待准备 | 个人申请提供身份证正反面；企业申请提供营业执照副本并盖章 |
| 软件鉴别材料-源程序 | 待生成 | 通常提交前 30 页和后 30 页，不足 60 页提交全部 |
| 软件鉴别材料-文档 | 已生成草案 | 用户操作说明书或设计说明书，通常提交前 30 页和后 30 页，不足 60 页提交全部 |
| 权属证明文件 | 视情况准备 | 独立开发一般可不额外提交；合作/委托/受让/公司申请建议准备协议 |

## 2. 建议补充材料

- 项目功能说明；
- 技术架构说明；
- 开发过程记录；
- Git 提交记录截图或导出；
- 线上部署/商用证明；
- 著作权归属确认书；
- 开源组件清单；
- 权利人内部决议或授权委托书。

## 3. 版本一致性核查

提交前检查：

- 申请表软件名称与说明书页眉一致；
- 申请表版本号与源代码/说明书页眉一致；
- 著作权人名称与身份证明、签章一致；
- 开发完成日期不晚于首次发表日期；
- 源代码材料没有明显第三方版权声明、他人公司名或敏感密钥；
- 说明书中的功能描述与实际软件一致；
- 所有 PDF 清晰、A4、页码连续。

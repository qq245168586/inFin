# 04. 线上提交步骤

以下为计算机软件著作权登记的线上办理步骤。具体页面名称和上传要求可能随中国版权保护中心系统调整，提交时以系统当前提示为准。

## 1. 进入官网与登记系统

1. 打开中国版权保护中心官网：`https://www.ccopyright.com.cn/`
2. 进入著作权登记系统：`https://register.ccopyright.com.cn/login.html`
3. 注册账号或登录已有账号。

## 2. 实名认证

1. 个人申请：选择个人实名认证，按系统要求上传身份证明并验证手机号。
2. 公司申请：选择机构实名认证，上传营业执照、经办人身份证明、授权材料等。
3. 等待实名认证审核通过。

## 3. 新建软件著作权登记申请

1. 选择“计算机软件著作权登记”或“软件登记”业务。
2. 新建申请。
3. 按申请表填写软件名称、简称、版本号、开发完成日期、首次发表情况、开发方式、权利取得方式、硬件环境、软件环境、编程语言、源程序量、功能简述等。
4. 确认所有版本号和软件名称与源代码、说明书完全一致。

## 4. 准备并上传材料

通常需要上传：

1. 申请表签章页或系统要求的确认文件；
2. 申请人身份证明；
3. 源程序鉴别材料；
4. 用户手册/设计说明书/使用说明书等文档鉴别材料；
5. 权属证明文件，如合作开发协议、委托开发合同、任务书、转让协议等（如适用）。

## 5. 提交、受理与补正

1. 在线检查材料并提交。
2. 登记机构形式审查后，符合要求的予以受理。
3. 如收到补正通知，应在通知期限内按要求补正。
4. 审查通过后，可查询公告并下载/领取登记证书。

## 6. 实务注意事项

- 申请材料建议全部保留一份，方便补正时保持一致；
- 源代码和文档材料的页眉建议写软件全称和版本号；
- 代码里不要出现其他公司或个人版权声明；
- 不要提交密钥、账号、服务器密码、数据库真实敏感数据；
- 如申请人为公司，但代码实际由个人先开发，建议先补权属协议；
- 如存在合作开发，需明确共同著作权人或权利归属；
- 如软件已对外发表，首次发表日期和地点要如实填写。

## 7. 官方依据

- 中国版权保护中心官网：`https://www.ccopyright.com.cn/`
- 中国版权保护中心登记系统：`https://register.ccopyright.com.cn/login.html`
- 《计算机软件著作权登记办法》参考页面：`https://www.sz.gov.cn/cn/xxgk/zfxxgj/zcfg/content/post_8965812.html`
- 北京政务服务“计算机软件著作权登记初审”材料要求参考：`https://banshi.beijing.gov.cn/pubtask/task/1/110000000000/3e283672-76be-4c8c-98e8-0bebe9bd06bf.html?locationCode=110000000000&serverType=1002`
- 中国版权保护中心是国家版权局认定的软件登记机构。
- 《计算机软件著作权登记办法》第九条规定，申请软件著作权登记应提交申请表、软件鉴别材料和相关证明文件。
- 《计算机软件著作权登记办法》第十条规定，软件鉴别材料包括程序和文档鉴别材料，通常由前、后各连续 30 页组成。
- 北京市政务服务事项对申请表在线打印、A4、签章、页码、版本号一致等要求作了汇总说明。

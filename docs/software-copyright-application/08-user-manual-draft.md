# 08. 用户操作说明书草案

软件名称：Infini 团课训练场馆运营系统软件 V1.0

## 1. 软件概述

Infini 团课训练场馆运营系统软件用于支持团课训练场馆的课程制作、课程排期、教练控课、TV 多屏播放和设备运维。系统面向管理员、编课人员、场馆教练和运维人员提供不同入口，并通过 Android TV 客户端在训练现场展示课程内容。

## 2. 角色说明

- 管理员：管理场馆、账号、课程包、TV 设备和应用版本；
- 编课人员：管理动作库、课程、模板和排课；
- 场馆教练：查看课表、预览课程、控制 TV 播放、绑定屏幕；
- 运维人员：查看设备在线状态、版本、MQTT 日志和运行异常；
- TV 客户端：接收课程资源和控制指令，展示训练内容。

## 3. 管理端操作

管理员登录 Admin Web 后，可以进入场馆管理、账号管理、课程包管理、设备管理和版本管理页面。

### 3.1 场馆管理

管理员可以新建场馆、编辑场馆名称、查看场馆 namespace、绑定场馆账号、绑定课程包、查看当前启用课程包和设备状态。

### 3.2 课程包绑定

管理员选择场馆后，可以查看该场馆已绑定课程包，新增或解除课程包绑定，并设置当前启用课程包。场馆当前启用课程包决定 Coach 和 TV 当前读取的课程与排课。

### 3.3 TV 设备管理

管理员可以查看 TV 设备编号、屏幕号、在线状态、版本号、缓存状态和最近心跳时间。必要时可解绑设备或下发应用更新。

## 4. 编课端操作

编课人员登录 Course Web 后，可以管理动作库、课程库、模板库和排课。

### 4.1 动作库

编课人员可以上传动作视频，设置动作名称和动作分类。系统会保存媒体资源，并为动作生成或展示视频封面。

### 4.2 课程编辑

编课人员可以创建课程，填写课程名称、设计者、版本和课程说明。课程通常包含热身、正式训练和冷身三部分。

正式训练部分可以配置 Pod、视频组、站点、work/rest 时间、switch 逻辑、补水或换区提示。课程保存后形成结构化课程脚本。

### 4.3 模板使用

系统支持热身模板、冷身模板、训练视频组模板和整课模板。编课人员可以通过模板快速生成课程骨架，提高课程制作效率。

### 4.4 排课

编课人员选择课程包后，可以为指定日期安排课程。排课完成后，绑定该课程包的场馆即可在 Coach Web 和 TV 端读取对应课程。

## 5. 教练端操作

场馆教练登录 Coach Web 后，可以查看当前场馆当前课程包的今日课表。

### 5.1 查看课程

教练可以查看课程名称、课程说明、动作内容和课程计划，确认当天课程安排。

### 5.2 预览课程

教练选择课程后，可发起预览。系统创建 preview session，并通知 TV 展示预览状态。TV 收到通知后会向 Server 拉取权威 session 和课程资源。

### 5.3 开始课程

教练点击开始后，Server 创建或更新 playback session，并生成统一开课时间。TV 端根据统一开课时间进入训练播放，保证多屏同步。

### 5.4 暂停、继续和结束

上课过程中，教练可以暂停、继续或结束课程。相关控制会通过 Server 和 MQTT 通知 TV，TV 再拉取权威 session 状态并更新播放。

### 5.5 绑定 TV 屏幕

未绑定 TV 会展示二维码。教练扫码后选择屏幕号，系统将设备绑定到当前场馆和屏幕号。绑定成功后 TV 进入今日课表页面。

## 6. TV 客户端操作

TV 客户端运行在 Android TV 或电视盒子上。

### 6.1 未绑定状态

首次启动时，TV 展示二维码和设备信息。教练使用 Coach Web 扫码绑定。

### 6.2 今日课表

绑定后，TV 根据场馆 namespace 拉取当天课表和课程资源摘要。若资源发生变化，TV 下载并校验课程媒体文件。

### 6.3 训练播放

课程开始后，TV 根据屏幕号展示竖屏或横屏 UI。竖屏显示动作视频、训练状态和倒计时；横屏显示课程信息、进度和提示。多个屏幕通过服务端统一 session 保持同步。

### 6.4 缓存与异常

TV 优先播放本地缓存视频。网络异常时，TV 保留本地状态并在网络恢复后重新同步。无法播放资源时显示占位状态，便于教练和运维排查。

## 7. 运维操作

运维人员可以通过 Ops Web 查看 MQTT 事件、TV 心跳、设备在线状态、版本信息和控制消息记录，用于排查屏幕不刷新、课程不同步、设备离线等问题。

## 8. 常见异常处理

1. TV 不刷新课表：检查设备在线状态、场馆 namespace、课程包绑定、daily checksum；
2. 某个屏幕不播放视频：检查缓存状态、媒体 checksum、屏幕号绑定和本地文件可读性；
3. 多屏进度不一致：检查 playback session、serverStartAtMs、网络延迟和设备时间；
4. Coach 无法开课：检查账号权限、场馆绑定、课程排课和当前 session 状态；
5. MQTT 无响应：检查 MQTT Gateway、EMQX 连接、topic 和 namespace。

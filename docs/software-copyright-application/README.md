# Infini 软件著作权申请材料包

整理日期：2026-07-24

本材料包用于准备 Infini 项目的计算机软件著作权登记。它不是正式法律意见，最终提交前建议由知识产权律师或代理机构根据申请主体、权属证明、软件名称和提交系统最新要求复核。

## 推荐申请策略

优先申请 1 个综合平台软著：

- **Infini 团课训练场馆运营系统软件 V1.0**

理由：当前系统已经形成一个完整业务闭环，包含课程内容生产、排课、教练控课、TV 多屏播放、设备运维和场馆课程包管理。先申请综合平台便于快速建立整体权利证明。

如果后续要进一步保护核心模块，建议拆分补充申请：

- **Infini TV 多屏训练播放软件 V1.0**
- **Infini 课程编排管理软件 V1.0**
- **Infini 教练控课软件 V1.0**
- **Infini 场馆设备与课程包管理软件 V1.0**

## 官方依据与提醒

- 中国版权保护中心官网：<https://www.ccopyright.com.cn/>
- 中国版权保护中心登记系统：<https://register.ccopyright.com.cn/login.html>
- 《计算机软件著作权登记办法》参考页面：<https://www.sz.gov.cn/cn/xxgk/zfxxgj/zcfg/content/post_8965812.html>
- 北京政务服务“计算机软件著作权登记初审”材料要求参考：<https://banshi.beijing.gov.cn/pubtask/task/1/110000000000/3e283672-76be-4c8c-98e8-0bebe9bd06bf.html?locationCode=110000000000&serverType=1002>

- 《计算机软件著作权登记办法》第九条要求提交申请表、软件鉴别材料和相关证明文件；第十条规定源程序和文档鉴别材料通常为前、后各连续 30 页，不足 60 页则提交全部；第十一条列明身份证明、权属合同/任务书等证明文件要求。
- 北京政务服务事项也汇总了中国版权保护中心软件登记的受理条件、A4、签章、页码、版本号一致等提交要求。
- 中国版权保护中心官网和著作权登记系统可能会调整具体页面和上传口径，线上提交时以系统当前提示为准。
